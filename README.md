# Країна знає своїх героїв

Нова чиста версія сайту — без старої корупційної бази.

Ідея: публічні люди говорять і діють публічно; сайт фіксує конкретний факт, першоджерело, дату та контекст. Запис не є вироком або твердженням про винуватість.

Для старту база очищена: `data/people.json` містить порожній масив.
