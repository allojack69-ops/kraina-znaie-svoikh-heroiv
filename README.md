# Країна повинна знати своїх героїв — MVP

Статичний сайт без бекенду. Дані зберігаються в `data/people.json`.

## Важливо
Список імен взято з наданого користувачем переліку та очищено від дублікатів. Усі записи на старті мають статус `Потребує верифікації`.

Перед публікацією потрібно:
1. перевірити кожну особу за першоджерелами;
2. відрізняти підозру, обвинувальний акт, судовий розгляд і чинний вирок;
3. додати посади, короткий опис, номер/назву справи, дату та посилання;
4. додати фотографію з правом/умовами використання та вказати джерело;
5. вести `last_verified_at` і журнал оновлень.

Основні офіційні джерела:
- НАБУ: https://nabu.gov.ua/activity/reestr-sprav/
- НАЗК: https://corruptinfo.nazk.gov.ua/
- ВАКС: https://vaks.gov.ua/

Сайт не стверджує винуватість людини лише через наявність її в базі.

## Автоматичне оновлення

Проєкт містить `scripts/collector.py` та GitHub Actions workflow `.github/workflows/collector.yml`.

Колектор періодично читає офіційні публікації НАБУ, ВАКС та Апеляційної палати ВАКС, додає джерела до вже відомих профілів і створює нових кандидатів зі статусом `Потребує верифікації`. Він не перетворює підозру чи обвинувачення на вирок.

`data/inbox.json` — черга автоматично знайдених кандидатів для редакторської перевірки.

Для запуску вручну локально:

```bash
pip install -r requirements.txt
python scripts/collector.py
```
